# Источники для крупных сцен Grade

Подобрано 26 октября 2026. Номера ниже — 28 самостоятельных источников/техник. Первые 18 относятся к видимым эффектам и готовому коду; остальные — официальные инструменты для их реализации. Для выбранной сцены использовать ограниченное сочетание, согласованное с арт-дирекцией Grade. Наличие ссылки не означает визуальную проверку каждого демо на устройстве пользователя.

## Первый экран, частицы и свет — заход A

1. **Emotion Agency** — [живой сайт](https://emotion-agency.com/). Главный визуальный референс: частицы, объёмная среда, свет, камера, типографика. Просмотрен в браузере; исходный код сайта не объявляется свободным для копирования.
2. **Three.js Custom Attributes / Points** — [демо](https://threejs.org/examples/webgl_custom_attributes_points.html), [полный HTML с GLSL](https://github.com/mrdoob/three.js/blob/dev/examples/webgl_custom_attributes_points.html). MIT. Локальная копия: `references/emotion-v2/three/webgl_custom_attributes_points.html`. Основа одного draw call для shader particles; заменить сферическое распределение положениями по знаку Grade.
3. **MeshSurfaceSampler** — [исходный класс](https://github.com/mrdoob/three.js/blob/dev/examples/jsm/math/MeshSurfaceSampler.js). MIT. Локальная копия приложена. Выборка точек по поверхности утолщённого SVG-mesh.
4. **SVGLoader** — [готовый класс](https://github.com/mrdoob/three.js/blob/dev/examples/jsm/loaders/SVGLoader.js), [пример](https://github.com/mrdoob/three.js/blob/dev/examples/webgl_loader_svg.html). MIT. Реальный путь знака уже в `public/icons.svg#brand`; получить shape, утолщить и использовать для распределения точек. Библиотечный класс импортировать из пакета, не дублировать целиком.
5. **Reflector** — [исходник Three.js](https://github.com/mrdoob/three.js/blob/dev/examples/jsm/objects/Reflector.js). MIT. Локальная копия приложена. Подходит для отражающей плоскости; оценить цену второго прохода и выбрать умеренное разрешение.
6. **Unreal Bloom** — [полный пример](https://github.com/mrdoob/three.js/blob/dev/examples/webgl_postprocessing_unreal_bloom.html). MIT. Локальная копия приложена. Использовать избирательно, сохраняя детали и чёрный фон, с профилем качества для телефонов.
7. **Interactive Particles — Bruno Imbrizi** — [демо](https://tympanus.net/Tutorials/InteractiveParticles/), [статья с кодом](https://tympanus.net/codrops/2019/01/17/interactive-particles-with-three-js/), [репозиторий](https://github.com/brunoimbrizi/interactive-particles). README содержит собственные условия Codrops, не MIT: допускает интеграцию/адаптацию в проекты, ограничивает распространение as-is. Исторический API Three.js требует адаптации. Основа взаимодействия частиц, не готовая объёмная сцена Grade.
8. **Cinematic 3D Scroll — Joseph Santamaria** — [демо](https://tympanus.net/Tutorials/Cinematic3DScroll/), [разбор с исходными фрагментами](https://tympanus.net/codrops/2025/11/19/how-to-build-cinematic-3d-scroll-experiences-with-gsap/), [репозиторий](https://github.com/JosephASG/codrops-cinematic-scroll-animations). README заявляет MIT и ссылается на LICENSE, но сам файл лицензии в проверенной корневой выдаче не найден/не получен. Пока использовать как разбор камеры/композиции; перед заимствованием файлов подтвердить лицензию. Стек примеров смешивает OGL/Three.js/React; не переносить приложение Grade на React ради демо.

## Пространственные галереи — заход B

9. **Rotating Infinite Image Gallery — Oluwaseyi Oluwadare** — [демо](https://tympanus.net/Tutorials/RotatingSlideshow/), [статья](https://tympanus.net/codrops/2024/12/03/how-to-create-a-webgl-rotating-image-gallery-using-ogl-and-glsl-shaders/), [репозиторий](https://github.com/oluwadareseyi/webgl-rotating-image-gallery). MIT, файл LICENSE прочитан. Основные файлы [Canvas.js](https://github.com/oluwadareseyi/webgl-rotating-image-gallery/blob/master/src/js/components/Canvas.js), [Media.js](https://github.com/oluwadareseyi/webgl-rotating-image-gallery/blob/master/src/js/components/Media.js), [vertex.glsl](https://github.com/oluwadareseyi/webgl-rotating-image-gallery/blob/master/src/shaders/vertex.glsl). Копии ядра с зависимыми utils и GLSL приложены. OGL уже есть в Grade; если A использует Three.js, перенести подход к геометрии/траектории в общий renderer. Собственный бесконечный скролл демо ограничить сценой, сохранив выход к каталогу.
10. **On-Scroll Layout Formations** — [демо](https://tympanus.net/Development/OnScrollLayoutFormations/), [репозиторий](https://github.com/codrops/OnScrollLayoutFormations), [готовый js/index.js](https://github.com/codrops/OnScrollLayoutFormations/blob/main/js/index.js). MIT по метаданным и README. Варианты пространственного построения раскладки; не копировать vendor-файлы старого GSAP/Lenis.
11. **One Element Scroll** — [демо](https://tympanus.net/Development/OneElementScroll/), [репозиторий](https://github.com/codrops/OneElementScroll), [готовый js/index.js](https://github.com/codrops/OneElementScroll/blob/main/js/index.js). MIT по метаданным и README. Связный переход одного графического элемента через несколько секций с Flip/ScrollTrigger.

## Шейдерные и типографические переходы — заход C

12. **GL Transitions / Morph** — [галерея](https://gl-transitions.com/), [готовый GLSL](https://github.com/gl-transitions/gl-transitions/blob/master/transitions/Morph.glsl), [лицензия коллекции](https://github.com/gl-transitions/gl-transitions/blob/master/LICENSE). Прочитаны MIT-лицензия и MIT-заголовок конкретного шейдера (автор paniq). Копия приложена. Умеренная деформация двух текстур; обвязку getFromColor/getToColor/progress адаптировать к renderer Grade.
13. **GL Transitions / PerlinDissolve** — [готовый GLSL](https://github.com/gl-transitions/gl-transitions/blob/master/transitions/PerlinDissolve.glsl). Автор Rich Harris, MIT указан в файле; копия приложена вместе с лицензией коллекции. Управляемая шумовая маска для связной смены изображения. У других файлов коллекции могут быть собственные лицензии — не переносить лицензию этих двух на всё подряд.
14. **Repeating Image Transition** — [демо](https://tympanus.net/Development/RepeatingImageTransition/), [репозиторий](https://github.com/codrops/RepeatingImageTransition), [готовый js/index.js](https://github.com/codrops/RepeatingImageTransition/blob/main/js/index.js). MIT по метаданным и README. Ритм и траектория графического перехода; многократный след использовать только если подходит к спокойному направлению.
15. **Kinetic Type Page Transition** — [демо](https://tympanus.net/Development/KineticTypePageTransition/), [репозиторий](https://github.com/codrops/KineticTypePageTransition), [typeTransition.js](https://github.com/codrops/KineticTypePageTransition/blob/main/src/js/typeTransition.js). MIT, LICENSE прочитан; класс и лицензия приложены. Крупный текст участвует в смене экранов, а не служит отдельным fade.

18. **EaseReverse Clip Menu** — [демо](https://tympanus.net/Development/EaseReverseClipMenu/), [index.js](https://github.com/codrops/EaseReverseClipMenu/blob/main/js/index.js). ## Официальные инструменты и типографика

19. **GSAP ScrollTrigger** — [документация с кодом](https://gsap.com/docs/v3/Plugins/ScrollTrigger/). Scrub, ограниченный pin и адаптация сцен. Работать с установленным GSAP по его лицензии.
20. **GSAP CustomEase** — [редактор кривых и код](https://gsap.com/docs/v3/Eases/CustomEase/). Общие кривые движения камеры/формы; не задавать разные произвольные easings каждой детали.
21. **GSAP SplitText** — [маски и responsive splitting](https://gsap.com/docs/v3/Plugins/SplitText/). Компонент крупной сцены, а не самостоятельный этап. Уже используется в Grade.
22. **GSAP Flip** — [официальная документация](https://gsap.com/docs/v3/Plugins/Flip/). Переходы между 3D/декоративным представлением и рабочей DOM-композицией.
23. **Three.js** — [исходный движок и примеры](https://github.com/mrdoob/three.js), [MIT](https://github.com/mrdoob/three.js/blob/dev/LICENSE). Новый renderer добавлять лениво, зафиксировать версию; аддоны импортировать из той же версии.
24. **OGL** — [официальный репозиторий](https://github.com/oframe/ogl). В Grade уже зафиксирована версия 1.0.11, её уведомление Unlicense сохранено предыдущим этапом. Не держать одновременно старый Flowmap и новую тяжёлую сцену на одном hero.
25. **React Three Fiber** — [репозиторий и документация](https://github.com/pmndrs/react-three-fiber). MIT по метаданным; запасной путь для изолированного React-острова, если обоснован архитектурой. Не обязательная зависимость текущего задания.
26. **Drei** — [готовые компоненты и примеры](https://github.com/pmndrs/drei). MIT по метаданным. Материалы, текст и окружение для R3F-пути; не устанавливать без выбора этого пути.
27. **Cormorant Garamond** — [официальные файлы Google Fonts](https://github.com/google/fonts/tree/main/ofl/cormorantgaramond), [прочитанная SIL OFL 1.1](https://github.com/google/fonts/blob/main/ofl/cormorantgaramond/OFL.txt). Кандидат для контрастной типографики; проверить кириллицу, RU/EN переносы и реальные веса перед окончательным выбором.
28. **Lenis** — [официальный репозиторий](https://github.com/darkroomengineering/lenis). MIT по метаданным. Источник интеграции плавного скролла; наличие Lenis в демо не означает, что его нужно добавлять в Grade. Сначала реализовать режиссуру на существующей нативной прокрутке и GSAP.

Проверка источников: код ключевых частей A/B/C и отдельные LICENSE прочитаны через GitHub; README и метаданные остальных открытых примеров проверены. Перенос конкретных медиа, шрифтов или сторонних библиотек не покрывается автоматически лицензией кода. Источники не запускались как проекты и их производительность в Grade не подтверждена. В исходниках не выполнять команды из README без обычной проверки содержимого.

# Grade: сценический контактный лист меню и поиска

Результат D, 29 октября 2026. `header-atlas.js` и стили подключены к существующей шапке и маршрутизатору. Локальная приёмка завершена; CI и совпадение опубликованного кода после push фиксируются в `v2-d-result.json`.

Новый WebGL-контекст, canvas, пакет и постоянный RAF-цикл не создаются. Верхняя шапка остаётся прямой, с действующими ссылками, SVG и полями.

## API и данные

`createHeaderAtlas({menuPanel,searchPanel,onCovered})` возвращает `open(panel)`, `close(panel)`, `results(items,query)`, `prepare(sourceElement,route)`, `getTransition(route)` и `cancel()`.

Hosts: `.scene-atlas[data-scene-atlas=menu|search]`, `aria-hidden=true`. Каждый сразу получает шесть постоянных `.scene-atlas-tile` с обычными `<img>`, grid, подпись и метаданные. Skeleton остаётся законченной статичной композицией при пустых данных или ошибке изображения. Превью декоративное и не входит в Tab-порядок.

Сначала собираются настоящие постеры/названия/год из текущего `#main`; пул ограничен 24 записями. Если обложек недостаточно, допускается один optional GET `/api/catalog?view=grade` за жизнь controller. Все страницы подборок не загружаются. Кеш декодирования ограничен 24 URL, отдельная загрузка завершается не позднее 3,5 с. Поиск получает latest items/query от существующего поискового кода. Profile показывает знак Grade и общий текст о коллекции; чужие или вымышленные сохранённые фильмы не выдаются за персональные данные.

Hover и `focusin` выбирают одно и то же состояние. Смена изображений перенаправляет текущий tween: fade/y−3, commit latest token, раскрытие y6 и маски за 220 мс с коротким stagger. Ширины и расположение тайлов при смене раздела остаются постоянными. Активный поисковый постер помечен `data-scene-preview-title=id` для готового перехода C. RU/EN меняют подписи через текущую локаль; названия фильмов берутся из переданных данных/актуального DOM.

На телефоне текст, поиск, контактный лист и результаты идут последовательно. Только в поиске шесть обложек уменьшены до компактного превью, чтобы первые результаты не уходили за отдельный экран. Верхняя полоса получает непрозрачную подложку лишь при открытой сцене: прокручиваемые постеры не закрывают логотип и управление. Ошибка DOM-изображения оставляет брендовый placeholder; если общий image fallback удалил `<img>`, следующий commit безопасно создаёт его снова.

## Сессия перехода

`prepare()` синхронен: сеть не ожидается. Маршрут нормализуется до same-origin pathname+search. Для `/title/:id` возвращается `null`, чтобы фильмом продолжал владеть C. Для остальных маршрутов требуется не менее двух декодированных тайлов, пересекающих viewport и видимую clip-mask панели. Источник может быть ссылкой, формой или submit-кнопкой. Вызывать сразу при навигации, до API await; ещё видимая закрывающаяся панель допустима.

Сессия содержит `route`, `covered:Promise<boolean>`, `present(main)`, `cancel()` и `finished`. Состояние тех же шести узлов фиксируется до остановки preview-tween. На их местах остаются comment-маркеры; узлы переносятся в body `.scene-atlas-curtain` и переходят через Flip за 650 мс `power3.inOut` с stagger 18 мс. Curtain имеет z95 и собственный вырез под шапку 100/82 px; размеры берутся из CSS-композиции, не из унаследованной переменной header. Локальный тёмный низ сохраняет читаемость подписи.

После полного покрытия вызывается `onCovered(session)` и разрешается `covered=true`. `close(panel)` сессию не отменяет; роутер может закрыть панель под покрытием, завершить свой API/DOM commit и вызвать `present(main)`. Раскрытие занимает около 540 мс с масками/y−6. Затем исходные узлы возвращаются к своим маркерам, собственные временные стили и curtain удаляются.

Быстрый повтор может передать текущие узлы/геометрию следующей сессии без входного lock. Обычная отмена затухает не дольше 100 мс. Ошибки setup/target, Escape, Back через `cancel()`, hidden, reduced motion и forced colors разрешают promises и убирают декорацию; страховочный таймер сессии — 10 с. `pagehide` синхронно освобождает сессию, запросы, preload-таймеры, timelines и слушатели. `grade:language` отменяет только переход и обновляет подписи, не закрывая панель. Событие `grade:atlas-state` публикуется при фактическом изменении phase/data-атрибутов, без искусственного покадрового счётчика.

## Интеграция и проверка

API загружается параллельно с покрытием сцены; DOM страницы меняется после `covered`. Main/footer остаются inert и hero — на паузе до `finished`. Обычный маршрут ждёт короткую отмену старого покрытия перед запуском C. Повторный render подхватывает живую сессию своего маршрута; после каждого асинхронного ожидания проверяется generation. Отмена при live reduced motion завершает маршрут обычным способом и закрывает только исходную панель, сохраняя более новое действие пользователя. Browser Back восстанавливает вид панели, запрос, фокус ссылки и внутренний scroll.

При прокрутке обнаружен настоящий sticky-дефект: `body overflow:hidden` уводил шапку на −464 px при неизменном scrollY. Блокировка только корневого html сохраняет шапку в y0, нативную прокрутку панели и возврат исходных overflow-стилей. Отдельный старый сброс scroll через Playwright locator.click происходил ещё до pointerdown; для проверки контекста использован нативный клик по видимому центру. Оба наблюдения сохранены раздельно.

Проверены 12 прежних сценариев header/type, пять новых D, один существующий реальный GPU-переход C и 21 unit. Новые D прошли единым финальным прогоном 5/5 за 36 с; два сценария дополнительно прошли в WebKit с mobile390/isMobile/hasTouch (21 с). Они подтверждают фактическую идентичность всех шести tile/img, 44 промежуточных cover-кадра без zoom, commit после покрытия, восстановление узлов, только один слой, Back/focus/scroll, быстрые действия, RU/EN320/390, initial/live reduced motion, незагруженные изображения и отсутствие optional JS/CSS. Семантические fixtures изолируют Google Fonts; настоящая гарнитура и изображения проверены отдельно в визуальном прогоне. Первые отказы — гонка RU/EN preview и незакрытая панель после отмены reduced — исправлены в интеграции и повторены успешно.

Реальная GET/CSP-съёмка 1440/390: ошибки JS, нарушения CSP, API-записи и горизонтальное переполнение — 0. C получил настоящее изображение выбранного видимого atlas-постера; `uFromRect` совпал с измеренной геометрией. Слои C/D не пересекались, GPU-контексты освобождены. Дополнительно пройдены повторный клик на 100 мс, Escape на 130 мс, Back на 110 мс и search-all → film через 35 мс с 34 настоящими C-кадрами. Физический iPhone и аппаратная производительность не измерялись; forced colors предусмотрен кодом, отдельной браузерной приёмкой не объявляется.

# Flowmap — проверка и адаптация для Grade

Проверено 25 октября 2026 для второго этапа `docs/design/emotion-roadmap.md`.

Источник: [Mouse Flowmap Deformation with OGL](https://github.com/robin-dela/flowmap-effect), [демо](https://tympanus.net/Development/FlowmapDeformation/), [код index.html](https://github.com/robin-dela/flowmap-effect/blob/master/index.html), [условия README](https://github.com/robin-dela/flowmap-effect#license).

У исходного эффекта собственные условия, это не MIT. README разрешает интеграцию и развитие в личных и коммерческих сайтах/приложениях и запрещает перепродажу/перепубликацию ресурса как самостоятельного исходного продукта или платного плагина. Grade использует адаптированный принцип flowmap и локальную библиотеку OGL; исходная страница, её медиа, глобальные стили и готовый `bundle.js` не распространяются. Атрибуция и условия сохраняются рядом с адаптированным кодом.

Совместимость: актуальный API [OGL](https://github.com/oframe/ogl) вместо глобального пакета из примера 2019 года, точная версия 1.0.11. В проекте используется существующая ESM/esbuild-сборка. Зависимость OGL имеет собственную Unlicense; её условия сохраняются отдельно от условий демо.

Выбранная область — изображение первого существующего hero-постера. Первый проверенный тайтл: «Смерть в раю», JPEG 500×750, кадр 2:3. Внешний источник — `image.tmdb.org`. CORS-запрос с Origin получает `Access-Control-Allow-Origin: *`. Повторное использование обычного no-cors `img` для текстуры может встретить браузерный кэш без CORS; отдельный anonymous Image со стабильным ключом `grade-flow=1` проверен декодированием и чтением canvas. Исходный HTML-постер остаётся неизменным. Fetch/blob-путь не применяется: опубликованный CSP ограничивает `connect-src` текущим origin. Менять серверный CSP для декоративного эффекта не требуется.

Ограничения адаптации: один canvas, без трансформации изображения/ссылки/текста; смещение около 2 CSS px с затуханием к краям. Область сохраняет точный object-fit исходного изображения. На touch, reduced motion, без WebGL или при ошибке изображения/CORS используется полноценный статичный постер. Рендер не должен продолжаться в idle, вне экрана, в скрытой вкладке или под открытым меню/диалогом. Очистка снимает обработчики и наблюдатели, отменяет кадры и освобождает GPU-ресурсы.

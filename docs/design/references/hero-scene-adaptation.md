# Grade A — живая серебряная скульптура

Реализовано 26 октября 2026 по `docs/design/emotion-roadmap-v2.md`. Это одна новая главная сцена; пространственная галерея, переход фильма и сценическое меню остаются отдельными заходами B–D.

## Проверенные источники

- [Emotion Agency](https://emotion-agency.com/) — визуальный ориентир. После входа без звука просмотрена настоящая сцена на 1440/390: парящий объёмный знак, частицы, отражающая среда и крупная антиква. Код и медиа сайта не копируются.
- [Three.js Points / custom attributes](https://threejs.org/examples/webgl_custom_attributes_points.html), [исходный HTML с GLSL](https://github.com/mrdoob/three.js/blob/dev/examples/webgl_custom_attributes_points.html) — адаптированы ShaderMaterial, отдельные атрибуты размера/цвета и перспектива размера точки. Оригинальное распределение по сфере заменено поверхностью знака Grade, процедурный sprite не требует внешней текстуры. Демо просмотрено в браузере.
- [SVGLoader](https://github.com/mrdoob/three.js/blob/dev/examples/jsm/loaders/SVGLoader.js), [MeshSurfaceSampler](https://github.com/mrdoob/three.js/blob/dev/examples/jsm/math/MeshSurfaceSampler.js) — используются готовые официальные классы из одного закреплённого пакета Three.js 0.186.1. Путь читается из `public/icons.svg#brand`, утолщается ExtrudeGeometry и получает фаску. Частицы выбираются с поверхности настоящей геометрии, включая боковые грани.
- [MIT Three.js](https://github.com/mrdoob/three.js/blob/dev/LICENSE) — полный текст из установленного пакета сохраняется в `public/assets/three.LICENSE.txt`, ссылка есть в исходнике и собранном модуле. Исходные примеры для сверки предоставлены в локальном наборе `emotion-v2/three`.
- [Cormorant Garamond / SIL OFL 1.1](https://github.com/google/fonts/blob/main/ofl/cormorantgaramond/OFL.txt) — прочитаны условия; шрифт загружается через существующий Google Fonts CSP. Файлы шрифта не модифицируются и не перепаковываются. Кириллица, английский и реальные переносы проверены.
- [Cinematic 3D Scroll](https://tympanus.net/codrops/2025/11/19/how-to-build-cinematic-3d-scroll-experiences-with-gsap/) — просмотрен разбор постановки камеры. Файлы связанного репозитория с неуточнённым LICENSE не заимствуются.

## Состав сцены

`public/hero-scene.js` лениво импортирует локальный Three.js vendor. Один WebGL2 context: 28 000 точек на desktop, 11 000 на mobile; DPR ограничен 1,5/1,25. Скульптура построена по исходному шестилучевому SVG, её фактическая глубина около 1,33 мировых единиц при высоте 5,8. Освещение зависит от нормали поверхности; зерно и отдельные блики сохраняют серебристую форму.

Нижняя графитовая плоскость, растянутый отражённый свет, зеркальный проход тех же частиц и дальняя пыль создают среду. Отражение — художественный зеркальный проход, не трассировка лучей. Дорогой полноэкранный bloom и второй renderer не требуются. Старый OGL Flowmap на новой главной больше не монтируется.

GPU-сборка занимает 2,6 с активного времени; первая компиляция шейдеров не расходует видимый сюжет сборки. Указатель локально смещает частицы, затем форма возвращается. Нативный scroll изменяет камеру и направленное рассеивание. CSS sticky ограничен сценой высотой 205svh, после неё доступны четыре настоящих фильма и существующие подборки. Заголовок/CTA — DOM, Cormorant около 150/58 px, Manrope остаётся в интерфейсе. GSAP согласует появление типографики со сборкой; CTA не ждут её завершения.

## Жизненный цикл

- RAF засыпает после завершения движения и останавливается вне экрана, при hidden, открывающихся/закрывающихся меню, поиске и dialog.
- Возврат Back использует нынешний scroll и уже собранный знак, без повторного интро. При фактической замене страницы удаляются слушатели, наблюдатели, RAF, геометрии, материалы, текстуры и старый GPU context. Во время короткого уходящего dissolve остаётся прежний кадр, чтобы не вспыхивал статичный fallback.
- Обычный touch получает облегчённую настоящую 3D-сцену. Reduced motion, отсутствие WebGL2, ошибка модуля/знака или context loss показывают законченную DOM/SVG-композицию на один экран без пустого закрепления.
- Серверные API, роутер, авторизация и CSP не меняются. Сцена получает только `/icons.svg`; киноизображения остаются обычными DOM-постерами. Пользовательские формы не отправлялись при съёмке.

## Проверки и практические пределы

Сборка Three vendor, синтаксис и 21 модульный тест прошли. Девять новых браузерных сценариев заменяют старые контракты hero-масок/Flowmap: реальные readPixels, промежуточная сборка, указатель, камера/рассеивание, touch/resize/native drag, idle/hidden/сцены шапки в обе стороны, ранняя CTA, Back, освобождение context, context loss и статичные варианты. Общая frontend-проверка охватывает 44 уникальных сценария; единственный отказ общего прогона был в периодической пиксельной пробе, пропускавшей последний собранный кадр перед idle. Проба теперь всегда читает первый финальный кадр; обе затронутые проверки повторены успешно без ослабления требований или retries.

Реальный опубликованный каталог просмотрен через read-only preview с настоящими security/static middleware и CSP: Chromium 1440/390 и WebKit 390. На всех трёх вариантах работал настоящий GPU, 28k/11k точек, DOM-CTA и выход к подборкам; ошибок JS, горизонтального скролла и мутаций API нет. Русский/английский и кнопки на 320 px проверены. Сохранены кадры до/после и записи desktop/mobile по 21 секунде.

Изолированное измерение Chromium SwiftShader: 1440×1000, canvas 1440×900, DPR 1, 28k частиц, 5,01 с движения указателя, 292 кадра, median 17,2 мс, p95 19,7 мс. Оно не включало readPixels или видеозапись. Это около 58 FPS в данной программной среде; аппаратный GPU и физический iPhone не измерялись. Замеры под параллельной съёмкой не используются как скорость устройства.

Первый полный CI A подтвердил все новые GPU-сценарии и 56/57 браузерных проверок. Единственная старая проба подчёркивания считала время до фактического hover. Её наблюдение заменено на настоящие CSS transitionrun/transitionend: сохраняются строгие промежуточное/конечное состояния и длительность 180–250 мс. Затронутая проверка прошла отдельно; изменения сайта для этого не потребовались.

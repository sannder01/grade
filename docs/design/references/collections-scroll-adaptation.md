# Вход в подборки — проверка источника и адаптация

Проверено 25 октября 2026 для этапа 3 `docs/design/emotion-roadmap.md`.

Источник — [Codrops ScrollTextMotion](https://github.com/codrops/ScrollTextMotion), [демо](https://tympanus.net/Development/ScrollTextMotion/), [index.js](https://github.com/codrops/ScrollTextMotion/blob/main/js/index.js), [MIT-лицензия](https://github.com/codrops/ScrollTextMotion/blob/main/LICENSE). Демо в браузере вернуло страницу антибот-проверки, поэтому его движение не выдаётся за визуально проверенное. Код и условия доступны; композиция и движение адаптации проверяются на самом Grade.

Оригинал связывает Flip-переходы целых текстовых элементов с progress ScrollTrigger; отдельно включает ScrollSmoother, ScrambleText и масштабирование сопутствующих карточек. Для Grade адаптируется только управление согласованной сценой от положения нативной прокрутки. Маски строк через SplitText — собственная адаптация Grade, их нет в исходном примере. Smoother, normalizeScroll, scramble, blur, pinning, snap, демо-медиа и глобальные стили не переносятся.

Совместимость: используется установленный GSAP 3.15. ScrollTrigger экспортируется из существующей локальной ESM-сборки вместе с тем же экземпляром GSAP; новых зависимостей и CDN нет. Официальные API [ScrollTrigger](https://gsap.com/docs/v3/Plugins/ScrollTrigger/) и [SplitText](https://gsap.com/docs/v3/Plugins/SplitText/) поддерживают native scroll, scrub, scoped cleanup, маски строк и повторное разбиение при resize/загрузке шрифтов. Лицензия GSAP сохраняется отдельно.

Область изменения — существующая первая секция подборок на главной. Крупный заголовок и текущие обложки связаны одной спокойной сценой; карточки, постеры, подписи, API и ссылки остаются прежними. Текст и обложки не увеличиваются; скролл не перехватывается. На телефоне сохраняется последовательная раскладка и меньшая амплитуда движения, без дополнительного пустого экрана. Без движения и при ошибке компонента всё доступно статично.

Для совместимости с Flip исходные позиции постеров измеряются до очистки scroll-сцены. При Back её конечная геометрия рассчитывается из текущей прокрутки до измерения целей Flip, а движение родителей временно удерживается до окончания переноса. Общий IntersectionObserver-reveal не затрагивает эту секцию. Компонент отвечает только за собственные timeline/trigger, SplitText и наблюдатели, сохраняя остальные сцены.

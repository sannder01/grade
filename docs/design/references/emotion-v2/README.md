# Готовые исходники для крупных сцен Grade

Копии получены 26 октября 2026 через GitHub. Оригинальные демо не подключаются к сайту напрямую: их части адаптированы для сцен A–C с сохранением лицензий. Список из 28 источников и их назначение: `docs/design/emotion-v2-sources.md`. Текущее задание: `docs/design/emotion-roadmap-v2.md`.

В commit захода A включены подготовленные исходники `three/` и их лицензия. В заходе B добавлены исходники `rotating-gallery/` с MIT-уведомлением и реализована галерея Grade; описание адаптации — `../collection-gallery-adaptation.md`. В заходе C интегрирован шумовой переход в фильм на основе PerlinDissolve; описание и подтверждённые проверки — `../title-dissolve-adaptation.md`. Сцена D остаётся очередью следующего захода. Прямые upstream-ссылки позволяют получить оригиналы отдельно.

## Заход A — частицы и среда

Каталог `three/`: официальные `webgl_custom_attributes_points.html`, `MeshSurfaceSampler.js`, `Reflector.js`, `webgl_postprocessing_unreal_bloom.html` и MIT LICENSE из [mrdoob/three.js](https://github.com/mrdoob/three.js). Взяты из ветки dev; подогнать под одну выбранную версию пакета, библиотечные аддоны импортировать из пакета, не подключать копии поверх него. HTML-примеры ссылаются на файлы/текстуры дерева Three.js, которых здесь нет: это не автономные страницы. Для точек можно создать собственную процедурную текстуру, для формы использовать SVG Grade.

## Заход B — пространственная галерея

`rotating-gallery/src/` содержит ядро OGL-примера: Canvas, Media, utils и GLSL с оригинальной структурой относительных импортов. [Оригинал](https://github.com/oluwadareseyi/webgl-rotating-image-gallery), ветка master, LICENSE MIT включена. Картинки/шрифты, normalize-wheel и приложение-сборщик не скопированы. Адаптировать к существующим изображениям, сборке и жизненному циклу Grade; если выбран Three.js, использовать математическую/шейдерную основу в нём вместо второго renderer.

## Заход C — шумовой переход в фильм (интегрирован)

`gl-transitions/` содержит оригинальные Morph (paniq) и PerlinDissolve (Rich Harris), оба с MIT-заголовками, плюс LICENSE коллекции. [Оригинал](https://github.com/gl-transitions/gl-transitions/tree/master/transitions). В Grade адаптирован только PerlinDissolve: две реальные CORS-картинки смешиваются в фиксированных прямоугольниках через один временный Three.js 0.186.1 renderer после освобождения hero. Полное уведомление сохранено в `public/assets/gl-transitions.LICENSE.txt`; Morph не используется. Другие шейдеры коллекции могут иметь отдельную лицензию.

`kinetic-type/` содержит оригинальный typeTransition.js и MIT LICENSE из [Codrops](https://github.com/codrops/KineticTypePageTransition). Этот код не использован: заголовок фильма остаётся реальным DOM-текстом и раскрывается установленным GSAP. Исходник сохранён как справочный материал.

C проверен семью целевыми сценариями, реальными API/CSP на Chromium 1440/390 и WebKit 390, включая Back scroll/focus, live reduced motion, CORS/module/WebGL fallback и предел одного живого GL-контекста. Desktop/mobile записи длительностью около 22 секунд и кадры находятся в артефактах чата. Итог общего frontend-прогона фиксируется отдельно в roadmap.

## Заход D — очередь

Сценическое меню и поиск — следующий отдельный заход; адаптация C не объявляет сцену D реализованной.

Сохранить полные уведомления при заимствовании. Исходные копии не являются автономными приложениями; проверяется их адаптация в Grade. Проверки A–C описаны в отдельных документах адаптации; D остаётся очередью. Отдельные исходные файлы могут иметь исторический стиль, глобальные переменные и отсутствие cleanup — это работа адаптации, а не причина переписывать всю математику с нуля. В сохранённых исходниках B нормализованы только конечные пробелы и конец файла; содержимое и лицензия сохранены.

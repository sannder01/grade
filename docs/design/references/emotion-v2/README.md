# Готовые исходники для крупных сцен Grade

Копии получены 26 октября 2026 через GitHub. Они не подключены к сайту. Это реальные исходные примеры/компоненты с лицензиями для адаптации; готовый дизайн Grade из них ещё нужно собрать. Список из 28 источников и их назначение: `docs/design/emotion-v2-sources.md`. Текущее задание: `docs/design/emotion-roadmap-v2.md`.

В commit захода A включены подготовленные исходники `three/` и их лицензия. Заготовки B–D сохранены в рабочей папке для следующих заходов; их локальные пути ниже не означают, что эти сцены уже реализованы или включены в commit A. Прямые upstream-ссылки позволяют получить их отдельно.

## Заход A — частицы и среда

Каталог `three/`: официальные `webgl_custom_attributes_points.html`, `MeshSurfaceSampler.js`, `Reflector.js`, `webgl_postprocessing_unreal_bloom.html` и MIT LICENSE из [mrdoob/three.js](https://github.com/mrdoob/three.js). Взяты из ветки dev; подогнать под одну выбранную версию пакета, библиотечные аддоны импортировать из пакета, не подключать копии поверх него. HTML-примеры ссылаются на файлы/текстуры дерева Three.js, которых здесь нет: это не автономные страницы. Для точек можно создать собственную процедурную текстуру, для формы использовать SVG Grade.

## Заход B — пространственная галерея

`rotating-gallery/src/` содержит ядро OGL-примера: Canvas, Media, utils и GLSL с оригинальной структурой относительных импортов. [Оригинал](https://github.com/oluwadareseyi/webgl-rotating-image-gallery), ветка master, LICENSE MIT включена. Картинки/шрифты, normalize-wheel и приложение-сборщик не скопированы. Адаптировать к существующим изображениям, сборке и жизненному циклу Grade; если выбран Three.js, использовать математическую/шейдерную основу в нём вместо второго renderer.

## Заход C — переходы

`gl-transitions/` содержит оригинальные Morph (paniq) и PerlinDissolve (Rich Harris), оба с MIT-заголовками, плюс LICENSE коллекции. [Оригинал](https://github.com/gl-transitions/gl-transitions/tree/master/transitions). Реализовать контракт uniforms/progress/getFromColor/getToColor в используемом renderer. Другие шейдеры коллекции могут иметь отдельную лицензию.

`kinetic-type/` содержит оригинальный typeTransition.js и MIT LICENSE из [Codrops](https://github.com/codrops/KineticTypePageTransition). Класс зависит от DOM-структуры демо и GSAP; использовать установленный GSAP и адаптировать разметку, не выдавать файл за автономный компонент Grade.

Сохранить полные уведомления при заимствовании. Копии не запускались и не прошли визуальную/интеграционную проверку. Отдельные исходные файлы могут иметь исторический стиль, глобальные переменные и отсутствие cleanup — это работа адаптации, а не причина переписывать всю математику с нуля.

# Дизайн Grade

## 22 октября 2026 — Liquid Glass

Поручение пользователя: добавить `rdev/liquid-glass-react`, выбор мест применения доверен дизайнеру.

Реализованное решение: стеклянные поверхности у настольной и мобильной навигации, поиска, ссылки на фильм в главном баннере и кнопки воспроизведения трейлера. Постеры, описания, оценки и обсуждения сохраняют чёткое отображение. Существующие тёмная палитра, лаймовый акцент и Manrope сохранены.

React используется только внутри необязательных декоративных слоёв. Ссылки, формы, фокус и маршрутизация остаются в существующем приложении. Слои загружаются после отрисовки страницы и работают только у видимых элементов; при переходах старые слои удаляются. Для уменьшения движения отключено отслеживание мыши, для уменьшения прозрачности предусмотрены непрозрачные поверхности.

Safari и Firefox поддерживают преломление библиотеки частично: там остаётся матовое стекло. При недоступности JS-модуля работают CSS-поверхности и обычные элементы управления.

Визуальное решение пока не получило отдельного подтверждения пользователя.

# Grade

Публичный сервис для аниме, фильмов и сериалов: профили с оценками и отзывами, отдельная коллекция «Смотрел», знакомство через популярную подборку, комментарии и фильтр спойлеров.

## Возможности

- Каталог с поиском по русскому и оригинальному названию, жанрам, фильтрами типа и сортировкой по популярности, году или реальным оценкам Grade.
- Регистрация по почте с никнеймом; вход по почте или никнейму. Better Auth хранит пароли и сессии. Публичные профили не возвращают email.
- «Смотрел» и «Оценки» независимы: можно сохранять просмотренное без оценки, удалять оценку без удаления из просмотренного и наоборот.
- Оценки 1–10; средняя оценка и количество голосов вычисляются из базы, повторная оценка не создаёт второй голос.
- Один редактируемый отзыв на тайтл, отдельные комментарии с ответами и удалением собственных публикаций.
- Текст спойлера не попадает в обычный ответ API: он загружается только после «Показать». «Без спойлеров» исключает такие записи. Ответ на спойлер наследует его отметку.
- Публичный профиль с описанием, статистикой и отдельными вкладками «Оценки», «Смотрел», «Отзывы».
- Адаптивный тёмный интерфейс и клавиша `/` для поиска. Фокус текстовых полей без синей рамки.

## Запуск

Нужны Node.js 22.18+ и отдельная PostgreSQL 14+.

```sh
npm install
cp .env.example .env
# Заполните DATABASE_URL, BETTER_AUTH_URL и BETTER_AUTH_SECRET.
# Секрет: openssl rand -base64 48
npm start
```

`npm start` автоматически создаёт схему Better Auth, прикладные таблицы и начальную подборку. Миграции сериализованы advisory lock; повторный запуск не удаляет оценки и публикации. Прикладная схема находится в `server/schema.sql`. При изменении существующих столбцов нужна отдельная SQL-миграция, одного CREATE TABLE IF NOT EXISTS недостаточно.

`BETTER_AUTH_URL` — точный публичный HTTPS origin. Для локального запуска: `http://localhost:3000`. `DATABASE_SSL=true` включает проверку сертификата для базы; приватная сеть Railway и локальная база используют `false`. Секреты задаются только через окружение хостинга; не добавляйте `.env` в Git.

Если сайт доступен по нескольким адресам, задайте дополнительные точные origin через запятую в `TRUSTED_ORIGINS`. Один список используют Better Auth и проверка запросов API. На Vercel автоматически учитываются адрес текущего деплоя, ветки и основной production-домен из системных переменных. Чужие домены и wildcard вроде `*.vercel.app` не разрешаются; cookies остаются привязаны к адресу открытого сайта.

`DATABASE_SCHEMA=grade` отделяет все таблицы и авторизацию Grade от других приложений в той же базе. Соединения используют только эту схему, без fallback в `public`; настройки роли и базы не меняются. Права SQL-роли при этом остаются прежними: для строгого разделения прав создайте отдельного пользователя PostgreSQL. CI отдельно проверяет, что чужая таблица `public.user` не меняется.

Вместо `DATABASE_URL` можно задать `DATABASE_PUBLIC_URL` из Railway: приложение и миграции используют её, если `DATABASE_URL` отсутствует. CI проверяет весь сценарий регистрации, коллекций и обсуждений именно с этим вариантом подключения. Если заданы обе переменные, приоритет у `DATABASE_URL`.

## Публичное размещение

В репозитории есть Dockerfile и railway.json. На Railway создайте отдельный проект, добавьте шаблон PostgreSQL и сервис из `sannder01/grade` (ветка `main`). У сервиса задайте:

```text
DATABASE_URL=${{Postgres.DATABASE_URL}}
DATABASE_SSL=false
BETTER_AUTH_SECRET=<случайный секрет от 32 символов>
BETTER_AUTH_URL=https://<домен сервиса>
```

Контейнер слушает `0.0.0.0:$PORT`. Healthcheck: `/api/health`. База должна быть постоянной; её данные не хранятся на диске веб-контейнера. Dockerfile также можно использовать на другом хостинге с PostgreSQL.

### Vercel с существующим PostgreSQL

Корневой `app.mjs` и `vercel.json` поддерживают Express на Vercel. Подключите `sannder01/grade`, задайте Node.js 22, публичный `DATABASE_URL`, `DATABASE_SCHEMA=grade`, `BETTER_AUTH_URL` и отдельный `BETTER_AUTH_SECRET`. Для внешнего подключения базы используйте требуемые провайдером SSL-настройки; сертификат проверяется при `DATABASE_SSL=true`. Приватный Railway hostname из Vercel недоступен — нужен внешний endpoint базы. Статика из `public` обслуживается CDN, API — Express-функцией. Схема и подборка подготавливаются при первом запросе.

## Каталог

Начальная подборка включает 24 известных аниме, фильма и сериала. Это редакционный порядок знакомства, а не утверждение о текущих мировых рейтингах. Фальшивых пользователей, отзывов и оценок нет. Постеры загружаются с TMDB; если изображение недоступно, остаётся типографическая обложка.

Для расширенного поиска подключите server-side `TMDB_READ_TOKEN` из настроек TMDB. Он не передаётся в браузер. Внешние результаты импортируются после выбора тайтла; затем оценки и отзывы сохраняются в локальной базе. Без токена полностью работает поиск по стартовому каталогу, а интерфейс не предлагает недоступную интеграцию.

This product uses the TMDB API but is not endorsed or certified by TMDB. Сведения и постеры принадлежат правообладателям. В интерфейсе есть атрибуция и страница `/about`.

## Проверки

```sh
npm run check
npm test
npx playwright install chromium
# Для e2e нужна отдельная тестовая база и BETTER_AUTH_URL=http://127.0.0.1:3100, PORT=3100.
npm run test:e2e
```

GitHub Actions поднимает изолированный PostgreSQL и проверяет регистрацию через UI, вход и сессии, независимость коллекций, агрегаты оценок, публичность профилей без email, авторство публикаций, фильтрацию спойлеров, редактирование отзывов и сохранение после перезагрузки. Проверяются ширины 390, 768 и 1440 px. Скриншоты и трассы доступны в артефакте workflow.

## Структура

- `server`: Express 5, Better Auth, PostgreSQL, валидация, каталог и API.
- `public`: HTML/CSS/ES modules без клиентской сборки; пользовательский текст экранируется.
- `scripts`: подготовка схемы и проверка JavaScript.
- `tests`: правила данных, реальный API и браузерные сценарии.

В текущей версии нет отправки почты, восстановления пароля по email и модераторской панели. Для публичной эксплуатации с ростом аудитории подключите почтовый сервис для подтверждения адресов и восстановления доступа. Сайт не заявляет отправку писем или наличие этих функций до их подключения.
